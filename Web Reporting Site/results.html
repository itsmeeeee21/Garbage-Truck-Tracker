Results

Results, Discussion, and Recommendation

Summary of Results

The usability testing for the Garbage Truck Tracker prototype utilized the System Usability Scale (SUS) to measure real-time tracking accuracy and user confidence. Overall, the data reveals a robust core architecture with specific friction points during the initial onboarding phase.

Discussion of Findings

System Efficiency & Ease (Q3):

A significant majority of participants agreed the system was easy to navigate once active, indicating that the Live Map interface is intuitive and requires minimal instruction for operational use.

Onboarding Friction (Q10):

Contradicting the operational ease, many users felt a high learning requirement before "getting going." This suggests that the initial setup or account configuration is the primary source of user anxiety.

Technical Dependency (Q4):

The data shows a split in confidence; a notable segment of users still feels they would require technical assistance to operate the tracker, highlighting a need for simplified self-service documentation.

Metric Category Key Analysis
Integration Functions were perceived as well-integrated and cohesive (Q5).
Consistency High marks for consistency; the UI does not behave unexpectedly (Q6).
Learnability Participants believe new users would learn the map features very quickly (Q7).

Recommendations

  • Streamlined Onboarding: Develop a "Quick Start" overlay to reduce the high perceived learning curve identified in Q10.
  • Push Notifications: Implement automated alerts when a truck is nearby to address the "Neutral" stance on frequent manual use (Q1).
  • Support Accessibility: Integrate a simple "Help" or "FAQ" tooltip to increase user confidence for those who feel they need technical assistance (Q4).
  • UI Contrast: Enhance marker visibility to maintain the high integration and consistency scores found in the survey.
